第二周作业：五维向量的五分类模型训练
姓名：Zhechen Tu

1. 任务定义
输入任意一个由五个有限实数组成的向量，最大值位于第几维，标签就是第几类。
例如 [1, 2, 9, 4, 5] 的标签为第 3 类。内部标签使用 0~4，对外显示为 1~5。
对于最大值并列的情况，标签约定取首次出现的位置（最小维度编号）。
NaN、正负无穷大、长度不为 5 的输入会被拒绝。

2. 数据与预处理
使用不同固定随机种子，分别生成 60000 条训练样本、10000 条验证样本、
10000 条独立测试样本。每一维独立采样自 [-100, 100] 的均匀分布。
用最大值位置生成监督标签；模型预测由训练得到的神经网络输出决定。
不使用输入向量的 argmax 代替模型预测，也不使用测试集选择参数或模型。

逐向量进行中心化与范围缩放，使整体平移和正比例缩放不改变输入特征。
计算前先除以最大绝对值，避免大数计算溢出；全零或全相等向量得到零特征。
这个预处理不需要从验证集、测试集拟合统计量。
数据保存在 results/dataset.npz，可检查标签、数据规模和划分。

3. 模型与训练
框架：PyTorch 2.6.0，Python 3.12，CPU。
网络：Linear(5,64) -> ReLU -> Linear(64,32) -> ReLU -> Linear(32,5)。
损失：CrossEntropyLoss，输入为未经过 softmax 的 logits。
优化器：Adam，初始学习率 0.002，余弦退火至 0.00005。
批大小：256；训练轮数：60；随机种子：20261022。
按验证集交叉熵最小的轮次保存模型，本次为第 60 轮。
最终评估前从 best_model.pt 重新加载模型，验证模型文件可独立推理。

4. 实际结果
未训练时验证准确率：11.05%。
训练结束验证准确率：99.72%。
独立测试集：9960 / 10000 正确，准确率 99.60%，宏平均 F1 为 0.9960。
五个类别的召回率、精确率、F1 和混淆矩阵均保存在 results/metrics.json。
测试集全部 40 条错误预测保存在 results/test_errors.csv。

额外分布测试（均未参与训练或模型选择，各 5000 条）：
正态分布：4986 / 5000，99.72%。
全负数指数分布：4940 / 5000，98.80%。
近并列压力测试：2842 / 5000，56.84%。
压力测试从 [-1,1] 采样，再将第二大数改成距最大数 0.000001~0.001。
这里两个候选值极接近，模型对分类边界的小偏差会产生明显影响。

5. 示例与局限
[1, 2, 9, 4, 5]：模型预测第 3 类，规则标签也是第 3 类。
五个明显最大值位置的示例、负数示例、大数示例均预测正确。
并列示例 [3, 3, 1, 0, -1] 本次预测第 1 类，符合标签约定。
全零示例 [0, 0, 0, 0, 0] 本次预测第 2 类，规则标签为第 1 类，预测错误。

训练后的分类器是统计近似。普通测试集的 99.60% 不代表能正确处理所有
任意向量；尤其是最大值相近、精确并列以及浮点精度极限的情况。
规则本身已经已知，若实际业务要求每个输入绝对正确，可直接用
np.argmax(vector)+1 计算精确规则结果；本作业保留神经网络预测来展示训练。
命令行会分别打印模型预测与规则参考，便于比较，二者没有互相替换。

6. 运行方法
在本目录创建 Python 3.12 虚拟环境后安装依赖：
python -m pip install -r requirements.txt

重新训练并生成全部结果（默认保存到 results，覆盖同名结果）：
python classifier.py

使用已保存的模型预测，不重新训练：
python classifier.py --predict 1 2 9 4 5

独立复核模型、数据及指标，不重新训练：
python verify.py

可用 --output-dir 指定其他结果目录，--epochs 指定训练轮数。
完整依赖锁定见 requirements_lock.txt。不同平台与版本可能出现小幅数值差异。
