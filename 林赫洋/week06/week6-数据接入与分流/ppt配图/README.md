## 口径说明（和课件正文一致）

- 评测集：**去掉与训练集重复的 1,099 条后的 8,901 条验证样本**（clean val）
- 指标：Macro-F1；左图另给 Accuracy
- 普通 Loss / 加权 Loss：同一份训练集、3 epoch、分层学习率、固定 seed=42

## 这三张图的实测数字

**类别加权（P25）**

| | Accuracy | Macro-F1 |
|---|---|---|
| 普通 Loss（无类别加权） | 0.5493 | 0.5344 |
| 加权 Loss（balanced） | 0.5420 | 0.5344 |

长尾类 recall 明显回升（故事 +0.33、电竞 +0.47），头部类有下降（证券 −0.16、房产 −0.09）——
**Macro-F1 打平、Accuracy 略降**，但业务上「整类不漏」比总分更重要，这就是加权的作用。

**混淆矩阵（P26）**：最容易被混的是 娱乐↔文化、科技↔财经、国际↔军事、农业↔房产。

**训练集规模（P17）**：15% 时差距 +0.057，100% 时 +0.026，见 P17 页正文。

## 怎么复现

```powershell
cd D:\badou\项目材料准备\_week6_loss_tricks
python plot_hires.py
```

脚本会读两份逐条预测（`ppt材料/week6_data_routing/bert_clean_pred.json` 与
本目录 `results/weighted_pred.json`，后者由 `dump_weighted_preds.py` 训练加权模型产出），
重新画到本目录。想改字号/配色直接改 `plot_hires.py` 里的 `figsize` 与 `dpi`。

注意：matplotlib 里**旋转的竖排中文（ylabel / colorbar label）会渲染成叠字**，所以这几张图的
中文标题都放在横向 title 里，脚本里不要把它们再改回 `set_ylabel("中文")`。
