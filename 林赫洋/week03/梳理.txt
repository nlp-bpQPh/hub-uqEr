流程：
    原始文本 → 归一化(normalize) → 字符表(vocab) → 定长编码(encode, MAX_LEN=40)
        → Embedding(64) → RNN(64) → 掩码MaxPool → LayerNorm → Dropout(0.3)
        → Linear(12) → CrossEntropy(交叉熵) + Adam(lr=1e-3, batch=64, 8 epochs)

各层在干什么：
    Embedding     字的 id 查表变成 64 维向量（是查表，不做乘法）
    RNN           按顺序读这 40 个向量，每一步的 hidden 带着"上文记忆"往后传；
                  顺序信息就是它比 MLP 强的地方（NL 任务里"字符出现的顺序"本身就是特征）
    掩码 MaxPool  句子定长 40，padding 位不能参与 pooling，否则短句会被 0 稀释；
                  用 mask 把 padding 置成 -inf 再取 max，得到"最长的一个真实位置"
    LayerNorm     在每条样本内部做归一化；和 BN 的区别是不依赖 batch 大小
    Dropout       训练时随机丢 30%，防过拟合（小模型 + 小数据才需要）

调参(按优先级)：
    数据：MAX_LEN：看需求，太小会截断，太大会浪费
    学习率：LR
    轮次：epochs或早停
    模型容量：embed_dim、hidden_dim
    batch_size、dropout、优化器：
        batch 64→128 主要影响稳定性而非最终精度；dropout 0.3 只在过拟合时往上调（0.5 封顶），欠拟合时应该往下调到 0
        Adam→SGD+momentum 这种换血，只有在前面全试完才考虑

训练时盯着三个信号：
    现象                            诊断	                            动作
train loss 降、dev_acc 不涨后回落	过拟合	               加数据 / 加 dropout / 减小 hidden_dim / 早停
train loss 和 dev_acc 都卡住	   欠拟合或数据问题         加大模型 / 提高 LR / 检查数据是否有错（标签错、编码错）
dev 很好、test 掉很多	dev/test    分布不一致，或 dev 被间接用于调参污染了	   检查切分方式；调参只用 dev，test 只碰一次
loss = NaN	                        LR 太大或数据有脏东西	                降 LR、检查异常样本
es ↔ pt 互错最多（35 / 14 条）   西语和葡语共享拉丁字母、拼写接近    短句不够分 → 加长文本；或加"语言先验/词典"特征
去掉重音符号后 vi 掉到 41/120     模型认的是"特定字符"不是整体分布    训练时随机去重音（数据增强）；这几类本来最依赖重音
日语去掉假名 57/100 判成中文      关键特征被拿掉了                    这类样本人类也难分，属于"分布外的极端情况"，别为它调模型
8~12 字符短句 0.912，20~30 字符 0.983   长度是准确率第一因素       短文本任务要把长度分档写进评估，不能只报总准确率

实测（v12，12 类，Embedding 64 / RNN 64 / LayerNorm / Dropout 0.3 / Linear 12，Adam lr 1e-3、batch 64、8 轮）：
    test（1800 条）      accuracy 0.9578，macro-F1 0.9579
    逐类最低             es 0.793 (F1)、pt 0.820 —— 一对互相吃掉的邻居；
                         最高 ar / hi / ru 都是 1.000
    长度分档             8~12 字符 0.912（396/434）、12~20 0.968、20~30 0.983、30+ 0.965
    test_hard（难度切片，1300 条）
        [short]      600 条 0.855
        [nodeaccent] 600 条 0.733（vi 只有 41/120，西班牙语 72/120）
        [nokana]     ja 100 条 0.200（57 条被判成 zh、7 条被判成 ko）
    读法：正常测试集 95.8% 看着很高，但难度切片一掉到 0.73 / 0.20，
    说明模型学到的是"字符集特征"而不是"语言结构"，一改字符就露馅。
