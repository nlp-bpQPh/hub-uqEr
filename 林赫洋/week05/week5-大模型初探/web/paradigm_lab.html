注意力内部（三种范式完全一样）：X [B, L, d] → Q / K / V [B, h, L, d/h] → scores [B, h, L, L] → 输出 [B, L, d]；唯一的区别就是 scores 上加的 mask 不同（见右侧）。Encoder-Decoder 里，Decoder 每一层的 K/V 都来自编码器输出 features（[B, h, Ls, d/h]），Q 来自解码器自身（[B, h, Lt, d/h]），所以在图里是一条红线从 features 分发到每一层。

判断标准：输出需不需要「生成」。需要 → 解码器；只需打分/打标签 → 编码器；输入输出要严格对齐（翻译 / ASR）→ 编码器 + 解码器。
三个要点
  • 范式 = mask 的组合方式，不是三套不同的网络。
  • Encoder-Decoder 多了一个 cross-attention：解码器每一步都要回看编码器的输出。
  • 今天的主流是 Decoder-only：训练信号最密、一个目标统一所有任务、工程最省。
