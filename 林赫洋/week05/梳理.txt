流程：
    build_sft_data.py   →  86 组课程问答（以「？」结尾的再加 2 种问法）= 250 条 data/sft_data.jsonl（质量 > 数量）
    common.py           →  chat 模板：<|user|>问题<|assistant|>回答<|end|>
                        →  loss mask：提问段 label 全设 -100，只学回答段（约 70% 的 token 有信号，预训练是 100%）
    sft_train.py        →  Wenzhong-GPT2-110M（110M 参数）+ 扩 3 个特殊 token → 全参微调
                        →  lr 2e-4、warmup 5% + 余弦退火、bf16、梯度裁剪 1.0、batch 8、12 轮
                        →  每步按 10% 概率换成通用语料，防灾难性遗忘
    common.generate     →  生成循环：一次只出一个 token，拼回输入再算，遇到 <|end|> 停
    chat.py             →  单轮 / 多轮对话（多轮 = 把历史拼进 prompt，模型本身没有记忆）

SFT 到底改了什么（第 5 周 PPT）：
    没变：模型结构、注意力掩码、训练目标（还是预测下一个 token）、推理方式
    变了：输出分布（接龙 → 回答）、对话协议（chat 模板）、停止行为（<|end|>）、说话风格
    三阶段：预训练（给知识）→ SFT（给回答的形式）→ 对齐（给偏好）
    一句话：SFT 不改结构，只改数据和 loss

调参：
    参数	        说明
1	lr	        2e-4。SFT 比预训练小 1~2 个数量级：太大 → 灾难性遗忘（只记得问答，忘了中文）；太小 → 12 轮也学不会
2	epochs	        12 轮。250 条数据要十几轮才记住；真实项目数据几万条时用 1~3 轮 + 早停
3	数据量	        86 组 × 3 问法。数据是 SFT 的天花板，模型答不出的东西，加数据比调参有用
4	mix_ratio	0.1。混入通用语料的比例：0 → 明显遗忘（问它别的只会答课程问题），0.3 → 格式学不牢
5	max_len	        256。实际样本不到 100 token，设太大只是浪费显存
6	batch_size	8。显存峰值约 5 GB（4060 8G 够用），再加大要 OOM
7	优化器	        AdamW + weight_decay 0.01 + 梯度裁剪 1.0；不用换 SGD，小模型 AdamW 更稳

训练时盯着三个信号：
    现象	                        诊断	                                动作
train_loss 降、val_loss 第 1 轮就涨	250 条数据必然过拟合	                正常现象，不用管；数据上万条时才谈早停
回答开头对、后面开始编	        数据太少，模型只会背开头	                加数据 / 加问法变体
一直往下写停不下来	        没学会 <|end|>	                        确认模板里有结束符，多训几轮
换个问法就答错	                泛化差：SFT 只学形式，不学知识	        数据里加这种问法；知识靠预训练
答得跟问题无关	                loss mask 写错（提问段也算进 loss）	        打印一条样本，看 -100 的位置对不对
loss 完全不降	                学习率太小 / 数据格式不对	        先 python sft_train.py --quick 看样本打印

实测（4060 Laptop 8G，12 轮 53 秒）：
    问：SFT是什么？
      基座  ：SFT是一种特殊的技术，一种新的技术，它将像自然…      ← 只会接龙
      SFT后 ：SFT是用指令数据教模型学会回答问题。                  ← 学会回答了
    问：BERT和GPT有什么区别？（数据里没有）
      SFT后 ：BERT是只做理解的编码器模型，用双向注意力。          ← 答得像，但不是知识
    显存峰值 5.02 GB；train_loss 偏高是因为混了 10% 通用语料（loss 天然大）
