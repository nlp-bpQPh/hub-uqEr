给定一个 5 维连续向量 x = [x0, x1, x2, x3, x4]，每个维度取值 [0, 1)，按照一套确定性、互斥、带优先级的业务规则，将其映射到 5 个风险等级之一。

- 输入维度：INPUT_SIZE = 5
- 输出类别数：NUM_CLASSES = 5
- 标签来源：规则函数 classify_risk(x) 直接生成，无人工标注、无标签噪声
- 数据规模：训练集 10000 条（每类 2000），评估集 500 条（每类 100）



输入特征定义：

| **维度** | **含义**     | **危险方向** | **说明**                     |
| -------- | ------------ | ------------ | ---------------------------- |
| **`x0`** | 退款强度     | 越大越危险   | 近期退款行为强度             |
| **`x1`** | 投诉强度     | 越大越危险   | 近期投诉行为强度             |
| **`x2`** | 拒付信号     | 越大越危险   | 拒付/争议信号强度            |
| **`x3`**   | 账户年龄     | 越小越危险   | 归一化年龄，越小表示账户越新 |
| **`x4`** | 异常登录强度 | 越大越危险   | 异地/夜间/异常设备登录强度   |


规则：

| 类别          | 触发条件（满足任一即可）     | 规则含义              |
| ------------- | ---------------------------- | --------------------- |
| **类 4 极高** | ① `x0 > 0.85` 且 `x1 > 0.85` | 退款与投诉同时极端    |
|               | ② `x2 > 0.90` 且 `x0 > 0.80` | 强拒付信号 + 高退款   |
|               | ③ `x4 > 0.90` 且 `x1 > 0.80` | 极强异常登录 + 高投诉 |
| **类 3 高**   | ① `x0 > 0.70` 且 `x1 > 0.60` | 退款与投诉双高        |
|               | ② `x2 > 0.80` 且 `x3 < 0.25` | 强拒付 + 新账户       |
|               | ③ `x4 > 0.80` 且 `x0 > 0.60` | 强异常登录 + 较高退款 |
| **类 2 中**   | ① `x0 > 0.60`                | 退款偏高              |
|               | ② `x1 > 0.60`                | 投诉偏高              |
|               | ③ `x2 > 0.70`                | 拒付信号偏高          |
|               | ④ `x3 < 0.20` 且 `x4 > 0.50` | 新账户 + 异常登录     |
| **类 1 偏低** | ① `x0 > 0.40`                | 退款轻度异常          |
|               | ② `x1 > 0.40`                | 投诉轻度异常          |
|               | ③ `x2 > 0.45`                | 拒付信号轻度异常      |
|               | ④ `x4 > 0.60`                | 异常登录轻度异常      |
| **类 0 低**   | 以上均不满足                 | 兜底类                |
