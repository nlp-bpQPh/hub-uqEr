# week07 信息抽取作业 · 开始阅读

> 何琳琳 · 2026-11-26 · 纯 CPU 环境（无 GPU）

## 一句话结论

纯 CPU 复现老师工程，并扩展为 **11 组单变量对比**（覆盖数据量 / 序列长度 / 预训练表示 / 输出层 / 任务分解 五个维度）。与老师同配置的复现误差 **0.0006**。

**本机的三个"第一"分属三种配置，不要混着记：**

- **论元 F1 绝对值最高**：BERT-4L + CRF + 解码期硬约束 —— **0.5286**（非法 BIO 84.6% → **6.13%**，后处理零训练成本）。它不是换了更强的模型，而是把同一份 BERT-4L 权重（0.3489）靠解码策略拉上来。
- **训练模型（不含解码后处理）论元最高**：BiLSTM-CRF —— **0.4609**（1.31M 参数 / 300s / 3.92ms，性价比冠军）。
- **类型判别与召回最高**：FinBERT-4L —— 类型 macro **0.8109**（全表第一）、召回 R **0.5187**；只换骨干（同解码器 / 同层数 / 同长度）时比 BERT-4L 高 **9.01** 点。

老师 12 层 linear 的 0.5630 是**跨来源天花板**，只比高低、不做减法（见报告附录 C）。三者叠加（FinBERT + CRF + 硬约束）预计可破 0.55，本轮未跑，理由与成本见报告 §8。
